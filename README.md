# Практический листок № 1

Проект подготовлен для запуска в Visual Studio Code.

1. Откройте файл `Практические_листки.code-workspace`.
2. Откройте `Практические_листок_1.ipynb`.
3. Выберите рекомендованный интерпретатор Python, если VS Code спросит.
4. Нажмите **Run All**.

Для работы нужны расширения **Python** и **Jupyter**. Установите Python-пакеты командой:

```bash
python -m pip install -r requirements.txt
```

Ноутбук содержит выполненные ячейки с проверенными результатами; их можно пересчитать командой **Run All**.
